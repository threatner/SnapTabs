# App store optimization plan (2026-11-18)

Written by a research agent on 2026-11-18 and saved here unchanged in substance. Tags: (verified [Sx]) = checked that day against the source list at the end; (from repo); (guess). Ready-to-paste description: [listing-draft.txt](listing-draft.txt). Companion UX review: [ux-review-2026-11-18.md](ux-review-2026-11-18.md).

## Headlines

- SnapTabs is not in the top 10 for "session manager", "save tabs", "restore tabs", "tab manager" or "tab groups" (verified [S1-S5]).
- At this size, an exact keyword in the title plus the **Featured** badge beat install count: Super Session Manager (~430 users) ranks #2 for "session manager" with the phrase in its title and the badge (rank verified [S1]; user count seen once [S14]).
- The store **name and summary come from the manifest** (`wxt.config.ts`), not STORE_LISTING.md (verified [S6], from repo), so changing them ships with a package.
- The category is already **Workflow & Planning**; the listing showed **178 users**, 5.0 from 7 ratings, no Featured badge, English only (verified [S6]).
- The listing's "zero outbound requests" claim is wrong today: `SessionDetail.svelte` loads favicons from google.com/s2/favicons with each tab's hostname (from repo). Fix or drop it before nominating for Featured.
- Competitors' users complain about lost sessions after updates/crashes and tab groups not coming back (Session Buddy v4, OneTab) (verified, anecdotal [S13, S15]). That is SnapTabs' opening.

| Competitor | Users | Rating | Pitch and title keywords |
| --- | --- | --- | --- |
| OneTab | 2M | 3.8 (14.6K) | "Save up to 95% memory", one list (verified [S7]) |

| Toby | 300K | 3.6 (3.3K) | "Tab Manager & Session Saver", sync, sign-in (verified [S9]) |
| Workona | 200K | 4.3 (3.8K) | "Tab Manager", sign-up funnel (verified [S10]) |
| Tab Session Manager | 100K | 3.5 (452) | "Save and restore... automatic saving" (verified [S11]) |
| Tabs Outliner | 100K | 3.2 (3.3K) | "Next Generation Session Manager" (verified [S12]) |

Common complaints: saved sessions lost after updates or crashes; tab groups and window layout not restored; sync behind accounts and paywalls (verified/seen once, anecdotal).

**The gap:** the free, no-account session manager that brings tab groups back intact, with opt-in safety nets so a crash or an update never costs you your tabs.

Policy (verified [S16, S17]): no keyword lists; no keyword repeated more than ~5 times unnaturally; no unattributed testimonials; the summary must not name competitors. "OneTab alternative" belongs off the store only (README, AlternativeTo).

## Promo tiles

- Small 440x280 (search cards, category lists [S17]): icon, "SnapTabs", "Save tabs. Restore later." at 40px or larger, no chips; must read at half size. The current chip text fails that (from repo image).
- Marquee 1400x560: a tab strip of ~30 favicons collapsing into one session card, "Close every tab. Lose nothing." No "best"/"#1" claims [S17].
- Tiles can't be localized (verified [S18]).

## Icon brief

One bold silhouette, at most two shapes, strokes ≥2px at 16px; suggested: stacked tabs with a return arrow (save + restore in one glyph). Keep the brand blue. Test at 16/32px on light and dark toolbars next to OneTab and Session Buddy. No UI or text inside [S17].

No account. Stays on your device." YouTube, ads off, linked from both stores [S18, S19].

## Localization

Listing languages appear only if the package has `_locales/<code>` and `default_locale` (verified [S18, S19]); the repo has neither (from repo). Step 1: move name and description into `_locales/en`. Step 2: es, pt_BR, de, fr, ja with translated name/summary/description, saying "Interface in English" until the UI is translated (guess: avoids uninstalls, which feed ranking [S20]). Order by the dashboard's installs-by-language once checked.

## Category and badges

Stay in Workflow & Planning (with Session Buddy and Toby) (verified [S6, S8, S9]). Featured badge: nominate through One Stop Support; criteria include best practices, UX/design quality, English support, no policy violations, free core features (verified [S20]). Before nominating: fix or drop the outbound-requests claim; add website, support and privacy-policy URLs. Established Publisher badge: verify publisher identity (verified [S20]).

## Ratings within policy

The current prompt (5 snapshots or 3 restores, shown to everyone) is compliant (from repo). Add: reply publicly to every review; a "Rate on the Chrome Web Store" link in README and GitHub release notes; consider 3 snapshots or 2 restores; on Edge, point the prompt to the Edge store instead of hiding it. Never reward, unlock features for, swap, or sentiment-filter reviews (verified [S21]).

## Edge differences

Search terms: 7 terms, 30 characters each, 21 words max: session manager; save tabs; restore tabs; tab saver; tab groups; save tab groups; crash recovery. Up to 6 screenshots (add "Private by design"), 300x300 logo, description 250-10,000 characters, short description from the manifest, certification up to 7 business days (verified [S19]). Write "Edge", not "Chrome".

## 30-day measurement

Baseline before changes: ~130 weekly users, 178 listed users, 7 ratings, ~440 installs. Weekly in Dashboard Analytics [S20]: impressions (target +50%), page views/impressions (no baseline yet), installs/page views (hold), uninstalls/installs (not worse), weekly users (200), ratings (12+), rank for 6 searches in a logged-out window (top 30 "session manager", top 10 "save tab groups"), page views by utm_source. Targets are guesses. Ship title/summary with v1.10, images in week 2, posts in week 3, so each change shows separately.
